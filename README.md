## 2. 주요 내용

### 모델 선택: ARIMA

- **RNN:** 데이터 타입 불일치 오류(float32와 int64)를 해결하지 못해 제외했습니다.
- **LSTM:** MinMax 스케일링과 10일 단위 윈도우로 3차원 입력을 구성해 학습까지 진행했습니다. 발표 시점까지 모델 정의 부분을 정리하지 못해 최종 모델에서는 제외했습니다.
- **ARIMA:** 종가가 정상성을 만족하지 않아 ADF, KPSS 검정으로 차분 차수를 추정했습니다(d = 1). 이후 `auto_arima`로 최적 차수를 찾고, 잔차 진단(Ljung-Box, Jarque-Bera)을 확인했습니다.

### 예측 방식과 평가

- 데이터는 시간 순서대로 7:3으로 나눠 학습과 테스트에 썼습니다.
- 뚜렷한 추세나 계절성이 없어 테스트 구간 전체를 한 번에 예측하지 않았습니다. 대신 한 시점씩 예측하고, 실제 값을 관측할 때마다 모형을 업데이트했습니다.

| 종목 | MAPE |
|---|---|
| 코오롱글로벌우 | 2.34% |
| 동부건설우 | 2.77% |
| IHQ | 4.67% |
| KH필룩스 | 3.07% |
| 퍼스텍 | 2.55% |

### 매수, 매도 시점

- **OBV:** 거래량 누적값과 20일 지수이동평균이 교차하는 시점을 신호로 잡았습니다. 매도 신호가 모두 결측으로 나와 사용하지 않았습니다.
- **MFI:** 14일 기준으로 계산해 80 이상이면 매도, 20 이하이면 매수 신호로 보았습니다.

### 뉴스 키워드 분석

- **가설:** 매수 시점 전날에는 긍정적인 단어가, 매도 시점 전날에는 부정적인 단어가 더 많이 나타날 것이다.
- **수집:** 종목별 매수, 매도 시점을 5개씩 무작위로 골라 그 전날의 네이버 뉴스를 수집했습니다. 수집 항목은 제목, 언론사, 날짜, 요약문, 링크입니다.
- **분석:** 요약문을 KoNLPy(Okt)로 형태소 분석하고, 조사, 어미, 한 글자 단어를 제외한 뒤 단어 빈도를 셌습니다.

<br>

## 3. 결과와 한계

- ARIMA는 5개 종목 모두 MAPE 5% 미만으로 예측했습니다. 다만 한 시점씩 업데이트하는 방식이라 "전날 값에 가까운 예측"에 가깝고, 장기 예측력을 보여주지는 않습니다.
- 뉴스 키워드는 "상승", "거래", "종목"처럼 시황 기사에 공통으로 나오는 단어가 대부분이었습니다. 그래서 긍정과 부정을 구분할 수 없었고, 가설은 검증하지 못했습니다.
- 뉴스를 날짜별이 아니라 종목의 매수, 매도 단위로 합쳐서, 날짜별 차이를 보지 못했습니다.
- 표본(종목당 매수, 매도 시점 5개씩)이 작아 통계적 검정을 거치지 못했습니다.

**다시 한다면**
- 기사 단위로 감성 점수를 매겨 날짜별로 비교하겠습니다.
- 매수, 매도 시점과 뉴스 데이터를 날짜 기준으로 연결해 분석하겠습니다.
